JavaScript Practical Tasks

Interactive implementation of variables, dialogs (alert, prompt, confirm), and console outputs.

Task 1 Create variables for Student Name, Age, and Mark and print all three

Stores student details in variables and prints them using console.log().

let studentName = "Alex Sharma";
let studentAge = 21;
let studentMark = 92.5;

console.log("Student Name:", studentName);
console.log("Student Age :", studentAge);
console.log("Student Mark:", studentMark);
Task 2 Ask user's name using prompt() and display it using alert()

Prompts the user to enter their name in a popup input box, then displays a welcome greeting using alert().

let userName = prompt("Enter your name:");
if (userName) {
    alert("Welcome, " + userName + "!");
}
Task 3 Ask user's age using prompt() and print it using console.log()

Takes user's age input via prompt() and logs the value into the console.

let userAge = prompt("Enter your age:");
console.log("User Age entered:", userAge);
Task 4 Ask the user a question using confirm()

Displays a confirmation box (OK / Cancel) and handles the Boolean result (true / false).

let isJavaScriptFun = confirm("Are you enjoying learning JavaScript?");
if (isJavaScriptFun) {
    console.log("User clicked OK (true)");
} else {
    console.log("User clicked Cancel (false)");
}
Task 5 Ask user's name and display it on the webpage using document.writeln()

Asks for user's name with prompt() and renders the greeting onto the document page.

let name = prompt("Enter your name to display on the webpage:");
if (name) {
    document.writeln("<h2>Hello, " + name + "! Welcome to JavaScript.</h2>");
}
