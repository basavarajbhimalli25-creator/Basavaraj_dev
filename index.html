Tasks 11 — 14 Post & Pre Increment/Decrement Operators

Predictions & Actual proofs for a++, ++a, a--, --a.

// Task 11: Post Increment -> a1=11, b1=10
let a1 = 10; let b1 = a1++;

// Task 12: Pre Increment -> a2=11, b2=11

// Task 13: Post Decrement -> a5=19, b5=20

// Task 14: Pre Decrement -> a3=19, b3=19

Task 15 Find the Final Values (Tracing Challenge)

Evaluates multi-step increments: a = 5; b = a++; c = ++a; d = b--;

let a4 = 5;
let b4 = a4++;  // b4 = 5, a4 = 6
let c = ++a4;   // a4 = 7, c = 7
let d = b4--;   // d = 5, b4 = 4

console.log(a4); // 7
console.log(b4); // 4
console.log(c);  // 7
console.log(d);  // 5
